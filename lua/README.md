# Sonic Physics — Lua + LÖVE2D
Celular: instale o app **LÖVE for Android** (Play Store), copie `sonic_lua.love` pro celular e abra com ele.
PC (teste): `love lua/` (LÖVE 11.x). Teclado: setas, Z/Espaço = pulo.
Tabela de animações: `ANIM` no topo de main.lua (linha/índice da sprite sheet) — ajuste os frames lá.
